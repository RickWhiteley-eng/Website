Getting Started

SimpleNotes opens any folder of .enex files — including a full Evernote export — and indexes the notes for full-text search. Click Open Folder… in the toolbar (or press ⌘O) to choose a directory.

To set a folder as your default (loaded automatically on every launch), use File > Set Current as Default.

Frequently Asked Questions

How do I import a .enex backup?

Export your notebooks or notes to .enex or .md files into a folder, then open that folder in SimpleNotes. Each .enex file becomes a NoteFolder. .md files are converted into individual notes. SimpleNotes reads and writes .enex directly — no proprietary database, no migration cost if you decide to leave.

Where are my notes stored?

Notes stay where you put them, in the .enex files on your Mac. SimpleNotes also creates a small SQLite search index named simplenotes_index.db next to those files; this index is rebuilt automatically and contains no data that isn't already in your .enex files.

How does the search work?

Search uses SQLite's FTS5 full-text engine with prefix matching, so typing cat finds cat, catalog, and category. You can use AND, OR, NOT, and "exact phrases". Enable Fuzzy Search in the toolbar to also match misspellings and similar words.

How do I encrypt sensitive content in a note?

Select the text you want to encrypt, then choose Edit > Encrypt Selection (or ⌘E). You'll be asked to set a password and an optional hint. Encrypted text is sealed inside the .enex file and only decrypted when you click on it and provide the password.

Important: if you forget the password, the encrypted content cannot be recovered. There is no backdoor.

How do I share a NoteFolder with someone else?

Use NoteFolder > Share via Google Drive… and connect your Google account. SimpleNotes uploads the selected NoteFolder to your own Google Drive and gives you a sharing link or invitation to send. The other person opens that link in their copy of SimpleNotes to subscribe to the folder.

Only NoteFolders you explicitly share are uploaded. Everything else stays local. SimpleNotes uses the drive.file scope, which only grants access to files SimpleNotes itself creates — it cannot see the rest of your Drive.

How do I export a note to PDF?

Select the note and choose File > Export to PDF… Formatting, colors, embedded images, and tables are preserved.

I attached an image but it doesn't appear inline.

Embedded image rendering happens after the note is saved. Save the note, then re-open it. If a specific image still doesn't show, please report it with the image format and approximate size — see the contact section below.

Can I use SimpleNotes without an internet connection?

Yes. SimpleNotes is fully functional offline. The only feature that needs the network is the optional Google Drive sharing.

Where is the user manual?

A full PDF user manual is bundled with the app. Open it from Help > User Manual.
